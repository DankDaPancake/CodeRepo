# Tài liệu workspace cũ

Các tài liệu, script và số liệu lịch sử được chuyển nguyên từ thư mục `docs/` ở workspace vào đây. Các đường dẫn trong tài liệu lịch sử phản ánh bố cục workspace tại thời điểm ghi và có thể cần điều chỉnh. Hai tài liệu đề xuất trùng tên nhưng khác nội dung được giữ riêng; bản còn lại nằm ở `../../de_xuat_checkpoint_sync_logging_hybrid.md`.

Các script và dữ liệu hỗ trợ cũ vẫn chỉ ở workspace local; chúng không được đưa vào PR dọn dẹp.
